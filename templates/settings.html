How to set up Ollama (free & local)
  1. Install Ollama from ollama.com/download (or winget install Ollama.Ollama).
  2. Start the server: run ollama serve in a terminal (the Windows app does this for you).
  3. Download the model once: ollama pull qwen2.5:3b.
  4. Set OLLAMA_URL and OLLAMA_MODEL in .env (or save them here), then restart the app.
